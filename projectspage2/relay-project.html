Home Automation with Relays

In this project, you will learn how to use a relay to control higher voltage or higher current devices. Microcontrollers are good at controlling small signals, but relays allow them to switch bigger loads like lights or appliances.

What You Will Learn

  • What a relay does
  • The difference between COM, NO, and NC terminals
  • How to control a relay with a microcontroller pin
  • How relays can be used in home automation

Hardware Needed

  • 2-channel relay board
  • ESP32 or Arduino development board
  • Jumper wires
  • Optional: small DC load such as an LED, fan, or motor

Relay Connections

  • COM: common connection from the power source
  • NO: normally open connection
  • NC: normally closed connection
  • VCC: power from the controller
  • GND: ground from the controller
  • IN1 / IN2: control pins for the two relays

Safety Warning

Be extremely careful with wall power or 120V AC. Contact with line voltage can be deadly. For learning, it is safer to test the relay with low-voltage DC loads first.

Arduino Code

#define RelayPin 13

void setup() {
    pinMode(RelayPin, OUTPUT);
}

void loop() {
    digitalWrite(RelayPin, LOW);
    delay(3000);

    digitalWrite(RelayPin, HIGH);
    delay(3000);
}

How It Works

Controlling the relay is similar to controlling an LED. The microcontroller sends a HIGH or LOW signal to the relay input pin. Depending on the wiring, the relay can turn a circuit on or off.
