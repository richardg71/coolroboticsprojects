GETTING STARTED

Learn your board.

01 — Introduction to the Development Board

Identify the ESP32-S3 module, screen, joystick, buttons, USB connectors, and expansion headers. Learn what each component does before writing code.

02 — Understand Inputs and Outputs

Inputs include buttons and joystick movement. Outputs include the display and other supported peripherals. A program reads inputs and updates outputs based on its logic.

03 — Introduction to C Programming

Learn about variables, conditions, loops, and functions before working through the board's provided C lessons.

04 — Understand Example Programs

Example programs demonstrate individual board features. Read the setup instructions, check the required toolchain, and run the examples supplied for your board version.
