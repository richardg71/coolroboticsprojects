BEGINNER LESSONS

Learn the essentials.

01 — What is an ESP32?

The ESP32 is a family of microcontrollers used in electronics and connected devices. Your development board lets you program the chip and connect components.

Unlike a basic Arduino Uno, many ESP32 boards include Wi-Fi and Bluetooth capabilities.

Important: ESP32 GPIO uses 3.3 V logic. Do not assume every 5 V Arduino sensor or module can connect directly to an ESP32 pin.

02 — Set up your programming environment
  1. Install Arduino IDE from the official Arduino website.
  2. Connect the ESP32 development board using its USB cable.
  3. Install the appropriate ESP32 board support package.
  4. Select the exact board model and available serial port.
  5. Upload a basic test sketch supported by your board.

Confirm the board's exact model before choosing pin numbers or a board profile.

03 — Understand breadboards and GPIO

A breadboard lets you make temporary electrical connections without soldering. GPIO pins are programmable connections used for digital input and output.

Learn to identify power rails, connected rows, ground, resistors, and component polarity.

Always check the ESP32 board's pinout and voltage requirements before wiring a component.

04 — Understand your sensors

The DHT11 measures temperature and humidity. A PIR sensor detects changes in infrared radiation associated with movement. A photoresistor changes resistance in response to light.

Each component has its own pinout, voltage requirements, and programming interface. Those details must be checked before building a circuit.

05 — Outputs, displays, and relays

LEDs provide simple visual output. A buzzer can produce sound. An OLED can show readings and text. A relay allows a low-power control circuit to switch a separate load.

For beginner activities, use suitable low-voltage circuits. Do not connect household mains electricity to a student breadboard project.
