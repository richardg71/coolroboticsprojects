Arduino Simon Says

In this project, you will build a Simon Says memory game using an Arduino, LEDs, buttons, resistors, and a speaker. The Arduino creates a sequence, and the player has to repeat it correctly.

What You Will Learn

  • How to use buttons as Arduino inputs
  • How to control multiple LEDs
  • How to play tones using a buzzer or speaker
  • How to use arrays and game logic in Arduino code

Hardware Needed

  • Arduino UNO
  • 4 buttons
  • 4 LEDs, preferably different colors
  • 4 220-ohm resistors
  • 1 200-ohm resistor
  • 1 speaker or buzzer
  • Jumper wires
  • Breadboard

How the Game Works

The Arduino turns on LEDs in a pattern. The player watches the pattern, then presses the matching buttons in the same order. Each round adds one more step to the sequence. If the player presses the wrong button or takes too long, the game ends.

Pin Setup

  • Red LED: pin 10
  • Green LED: pin 3
  • Blue LED: pin 13
  • Yellow LED: pin 5
  • Red button: pin 9
  • Green button: pin 2
  • Blue button: pin 12
  • Yellow button: pin 6
  • Buzzer pins: 4 and 7
