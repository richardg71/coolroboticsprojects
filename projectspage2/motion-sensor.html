Motion Sensor Project

In this project, you will use the HC-SR501 PIR sensor to detect motion. This sensor can sense movement nearby, which makes it useful for alarms, automatic lights, and security projects.

What You Will Learn

  • How a PIR motion sensor works
  • How to read HIGH and LOW signals from a sensor
  • How to turn on an LED when motion is detected
  • How to display motion status on a screen

Hardware Needed

  • HC-SR501 PIR sensor
  • Arduino or ESP32 development board
  • LED
  • Jumper wires
  • Optional: ST7789 display screen

Wiring

The PIR sensor only needs three wires: GND, VCC, and signal. Connect the signal wire to pin 13. The LED can be connected to pin 6.

Arduino Code

const int pirPin = 13;
const int ledPin = 6;

void setup() {
    pinMode(pirPin, INPUT);
    pinMode(ledPin, OUTPUT);

    Serial.begin(115200);
    Serial.println("Warming up sensor...");

    delay(30000);

    Serial.println("Sensor Active");
}

void loop() {
    int motionState = digitalRead(pirPin);

    if (motionState == HIGH) {
        digitalWrite(ledPin, HIGH);
        Serial.println("Motion Detected!");
    } else {
        digitalWrite(ledPin, LOW);
        Serial.println("Scanning...");
    }

    delay(500);
}

Important Sensor Notes

  • Sensitivity: controls detection distance.
  • Time Delay: controls how long the signal stays HIGH after motion.
  • Jumper: controls single trigger or repeatable trigger mode.
