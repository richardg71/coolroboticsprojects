Weather Station Project

In this project, you will use the DHT11 sensor to measure temperature and humidity. This is a simple but useful project because it teaches you how sensors collect real-world data and send that information to the Arduino or ESP32.

What You Will Learn

  • How to connect a DHT11 temperature and humidity sensor
  • How to read sensor data using Arduino code
  • How to view data in the Serial Monitor
  • How to display temperature on a screen

Hardware Needed

  • DHT11 sensor
  • Arduino or ESP32 development board
  • Jumper wires
  • Optional: ST7789 display screen

Wiring

The DHT11 has three main connections: ground, voltage, and signal. Connect GND to ground, VCC to 3.3V or 5V, and the signal pin to pin 13.

Simple Arduino Code

#include "DHT.h"

#define DHTPIN 13
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
    Serial.begin(115200);
    Serial.println(F("DHT11 Test"));
    dht.begin();
}

void loop() {
    delay(2000);

    float h = dht.readHumidity();
    float t = dht.readTemperature();

    if (isnan(h) || isnan(t)) {
        Serial.println(F("Failed to read from DHT sensor!"));
        return;
    }

    Serial.print(F("Humidity: "));
    Serial.print(h);
    Serial.print(F("% Temperature: "));
    Serial.print(t);
    Serial.println(F("°C"));
}

Troubleshooting

If the code gives an error for DHT.h, install the DHT sensor library in the Arduino IDE. Also check that the Serial Monitor baud rate is set to 115200.
